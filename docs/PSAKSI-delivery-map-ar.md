## ترتيب التنفيذ

1. الفهم والرد المركب: إبقاء جميع الأجزاء والشروط وعرض حدود التنفيذ، اختبارات منع الاستبدال والتسريب، ثم اختبار حي.
2. الحسابات والمشاركة: التسجيل والاستعادة، نموذج اكتشاف منفصل عن الحفظ الخاص، طلب/عرض بموافقة قابلة للسحب، وعزل بيانات مثبت.
3. مطابقة شخصين والتواصل: مسار كامل ببيانات مشاركين حقيقيين دون توليد ملفات وهمية.
4. المنتجات وAwin: فحص البرامج والبيانات المتاحة بالحساب؛ قبول العقود بواسطة المستخدم عند الحاجة.
5. Watch: تخزين وعامل ومراجعة موافقات وفروق وتنبيهات، ثم اختبار الانتهاء والإلغاء.
6. توسيع المجالات على نفس العقود والواجهات؛ تغطية معلنة لكل مصدر، لا وعد بأن كل حاجة لها نتيجة موجودة.

## حدود الإكمال

لا يمكن وصف الموقع بأنه «كامل بدون نقص» مع مصادر غير متصلة أو مستخدمين لم يشاركوا بعد. يعتمد إعلان الجاهزية على اختبارات مستخدم فعلية لكل مسار أعلاه. لا تعني قائمة التنفيذ أن هذه الميزات منشورة.


## تدقيق 27 أكتوبر 2026 — القائمة الحالية لمنع نسيان العمل

هذه مراجعة للكود، سجلات العمل، صفحة PSAKSI الحية، وعينات API. ليست شهادة بأن كل مجال أو كل جهاز تم اختباره. الواجهة الحالية 10Web، Render هو محرك البحث، وSupabase للحسابات والبيانات. لا إعادة بناء ولا خدمة بديلة.

### ما تم إثباته

- الحساب والملف الخاص والخلاصة والمنشورات والتفاعلات وصفحة العضو منشورة. صفحة حية في Safari أظهرت منشور السكن الأصلي بتاريخ23 أكتوبر ومنشور غرفة أحدث بتاريخ26 أكتوبر؛ لم ننشر طلبًا تجريبيًا أو نعدّل أي منشور خلال التدقيق.
- ترحيلات الملفات الخاصة والمنشورات والتفاعلات وبقاء المنشورات طُبقت سابقًا بالموافقة، وليس مطلوبًا تكرارها. بعض عناوين الملفات القديمة لا تزال تقول «غير مطبق»؛ التحديثات الأحدث تتقدم عليها.
- منشورات الناشر الجديد دائمة حتى الإغلاق؛ طلبات قديمة أخرى تحافظ على اختيار مدتها الأصلي. السجل الخاص ليس نشرًا عامًا، ولا يعاد فتح طلب أغلقه صاحبه.
- الدخول يبقى في اللسان نفسه؛ الخروج بعد30دقيقة خمول منشور ومختبر12حالة بساعة افتراضية. استمرار الدخول بين ألسنة المتصفح ليس منفذًا ولا يُفترض أنه خلل في كلمة المرور.
- إصلاح1a53dbb منشور: اقتباسات المتابعة لا تحمل أسطرًا جديدة في enum، النص والأدلة والقيود محفوظة، السكن ليس مكانًا عامًا، والنتائج غير المدعومة لا تُختلق.
- اختبار26أكتوبر: «ich such ein cafe» ← سؤال المدينة ← «Berlin» ←7أماكن فعلية. السكن بالألمانية والعربية صُنّف HOUSING مع إعلان عدم اتصال عروض فعلية.
- اختبار27أكتوبر: healthz=ok، BVG=4رحلات فعلية، GovData=2سجلين، تصنيف SOURCE_DERIVED وindependentlyVerified=false. فهم اللغة الحر فشل503، وسجل Render أثبت401؛ فحص نماذج OpenAI من نفس الخدمة أعاد invalid_api_key. هذا عائق جديد حالي، ولا يجوز الاستناد إلى نجاح26أكتوبر للقول إن AI يعمل اليوم.
- أمر الاختبار كان يشغل32اختبارًا فقط؛ أضيفت إليه اختبارات الميزانية والتشخيص والمتابعة ليشغل43اختبار إنتاج. نجحت43حالة في هذه المراجعة. تعديل اختبار السكن المحلي وملفاه غير المكتملين منفصلان وغير منشورين.

### تسلسل التسليم التالي

1. إزالة عائقR01 واختبار البحث المتقدم من الواجهة حتى لا نجذب أشخاصًا إلى مسار متعطل.
2. ربط مصدر سكن واحد حقيقي في برلين؛ الإبقاء على روابط البوابات الحالية موسومة بأنها روابط وليست إعلانات مستوردة.
3. إكمال المطابقة الاختيارية، ثم طلب التواصل والقبول، ثم الرسائل المباشرة. تصميم SQL وصلاحيات/مراجعة متكامل قبل طلب موافقة تطبيقه.
4. البحث المستمر والتنبيهات الاختيارية، وتوحيد اللغات والنصوص وحالات الهاتف.
5. تجربة صغيرة بمستخدمين حقيقيين ثمPWA. لا تطبيق مستقل جديد قبل ذلك.

### بوابة إعلان جاهزية تجربة برلين

- [ ] AI يعمل اليوم، لا بمجرد نجاح سابق.
- [ ] مصدر سكن فعلي واحد متصل وروابطه وحداثته صحيحة.
- [ ] مستخدمان حقيقيان يبحثان/يعرضان ويتطابقان دون كشف بيانات خاصة.
- [ ] المستلم يقبل التواصل قبل ظهور حقل إرسال الرسائل.
- [ ] الرسائل مستمرة وصلاحياتها معزولة والحظر يوقفها.
- [ ] البحث والنشر والسجل والإغلاق والدخول يعملون على الهاتف.
- [ ] اللغات الأربع تشرح الحقيقة نفسها، والمزايا غير المتصلة واضحة.
- [ ] الاختبارات القياسية كاملة وخطة الرجوع والاسترجاع واضحة.

لا تُغلق بنودH/C/S بتجربة محلية أو بيانات وهمية. هذه القائمة تحفظ كل ما بقي، ولا تدّعي تنفيذه. لا ترحيل إنتاج أو DNS أو دفع أو تغيير مفتاح تم ضمن هذا التدقيق.


### أوامر التحقق المعتمدة بعد هذا التدقيق

- `npm test`: يشمل43اختبارًا ملتزمًا بها؛ تعديل السكن المحلي السابق منفصل ولا يعني اكتمال المطابقة.
- `npm run build`: فحص تركيب JavaScript واستيرادات الخادم.
- `npm run check:live -- --production`: فحص المصادر الثلاثة والمتابعة المحددة على خدمة Render الحالية، مع نتيجة فشل إذا لم تتأكد النتائج. لا يستدعي AI ولا يختبر عروض شقق أو تواصل أعضاء.
- فحص AI منفصل بعد تصحيح R01 بواسطة صاحب الحساب؛ لن يُغيّر المفتاح الآن بناءً على اختياره أثناء التدقيق.
